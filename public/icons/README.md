# PWA icon assets

Production PNG icons for install and home screen:

| File | Size | Purpose |
| --- | --- | --- |
| `icon-192x192.png` | 192×192 | Android install / manifest |
| `icon-512x512.png` | 512×512 | Splash / high-resolution install |
| `icon-512x512-maskable.png` | 512×512 | Maskable adaptive icon |
| `apple-touch-icon.png` | 180×180 | iOS home screen |

Generated from `icon-app-launcher-1024.png` and `icon-launcher-ios-1024.png` (Flutter Mystic assets migrated to web).

Manifest is generated from `src/app/manifest.ts`.
